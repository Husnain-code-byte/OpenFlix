Frequently Asked Questions

OpenFlix is a free, open-source Android media client built in Flutter. It pairs a matte-black OLED interface and native libmpv playback with 1-click TMDB sync and Stremio/CloudStream addon support.
Download the arm64-v8a APK (~78 MB) for almost all modern Android smartphones. If you're using an older 32-bit device or aren't sure of your CPU architecture, grab the Universal APK (~118 MB).
OpenFlix is strictly a media client and metadata browser — it does not host or distribute any content. You connect your own third-party Stremio manifests or CloudStream repositories inside the Addons tab, and OpenFlix resolves and plays them via libmpv.
Yes. OpenFlix is profiled and tested daily on a 3GB RAM Android device with strict image cache limits, lazy collection loading, and custom carousel snap physics to keep scrolling smooth at 60fps.
OpenFlix includes a built-in update checker inside My OpenFlix. Whenever a new signed release drops on GitHub, the app automatically detects it and grabs the matching APK for your device.
